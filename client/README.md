# AI Environment Monitor — Client Application

This directory contains the React.js + Vite + TypeScript + Tailwind CSS application for the **AI Environment Monitor – Environmental Intelligence Network**.

For full application overview, architecture specifications, data models, and system features, please refer to the [Root README](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

The application runs on `http://localhost:8080/`.

## Key Commands

- `npm run dev`: Start local development server with Vite and TanStack Router
- `npm run build`: Production bundle build with Vite and Nitro
- `npm run preview`: Preview the production build locally
- `npx tsc --noEmit`: Verify TypeScript strict compilation without emitting files
